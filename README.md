# نظام إدارة الأسطول والمعدات
**الماسية الدولية للمعدات ش.م.م** — لوحة تحكم ويب (Web Dashboard) لإدارة الشاحنات والمعدات الثقيلة.

واجهة أمامية خالصة (HTML + CSS + JavaScript) بدون خادم، تحفظ بياناتها في المتصفح عبر LocalStorage، وجاهزة للنشر المجاني على GitHub Pages.

---

## هيكل الملفات

```
almasiya-fleet/
├── index.html          الصفحة الرئيسية
├── .nojekyll           يمنع GitHub Pages من معالجة الملفات بـ Jekyll
├── css/
│   └── style.css       التنسيقات (متجاوبة، RTL)
├── js/
│   ├── config.js       ⚙️ إعدادات المطور: الاسم، الشعار، الألوان، التنبيهات، القوائم
│   ├── i18n.js         الترجمة عربي / English
│   ├── data.js         طبقة البيانات (LocalStorage) + البيانات التجريبية
│   └── app.js          منطق الواجهة: الأدوار، الأقسام، النماذج، التنبيهات
└── assets/
    └── logo.svg        الشعار الافتراضي (استبدله بشعار الشركة)
```

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub (مثلاً `almasiya-fleet`).
2. ارفع **محتويات** المجلد (وليس المجلد نفسه) إلى جذر المستودع، بما فيها ملف `.nojekyll`.
3. من المستودع: **Settings ← Pages ← Build and deployment**
   - Source: `Deploy from a branch`
   - Branch: `main` والمجلد `/ (root)` ثم **Save**.
4. بعد دقيقة تقريباً يصبح الموقع متاحاً على: `https://<اسم-المستخدم>.github.io/almasiya-fleet/`

> للتجربة محلياً: افتح `index.html` مباشرة في المتصفح، أو شغّل `python -m http.server` داخل المجلد وافتح `http://localhost:8000`.

## التخصيص (للمطور)

افتح `js/config.js` وعدّل:

| الإعداد | الوصف |
|---|---|
| `systemName` / `companyName` / `companyNameEn` | اسم النظام والشركة |
| `logo` | مسار الشعار، مثلاً `assets/logo.png` |
| `theme.primary` / `theme.accent` / `theme.sidebar` | الألوان الأساسية |
| `alertDays` | التنبيه قبل انتهاء الرخصة والتأمين (افتراضياً 30 يوماً) |
| `maintenanceThreshold` | التنبيه قبل الصيانة الدورية بالساعات والكيلومترات |
| `plateTypes` / `vehicleTypes` / `insuranceTypes` | قوائم الاختيار (أنواع اللوحات والمركبات والتأمين) |
| `plateColors` | لون كل نوع لوحة: خصوصي أصفر، تجاري أحمر، مؤقت أسود، أشغال عامة أبيض |
| `vatRate` | ضريبة القيمة المضافة في الفواتير (5%) |

يمكن أيضاً تغيير الاسم والشعار والألوان من داخل اللوحة: ادخل بحساب **المطور ← إعدادات المطور** (تُحفظ في ذلك المتصفح فقط، بينما `config.js` يطبّق على الجميع).

## اللغة (عربي / English)

- زر **English / عربي** في الشريط العلوي وفي شاشة الدخول يبدّل الواجهة كاملة، مع تحويل اتجاه الصفحة (RTL ↔ LTR)، ويُحفظ الاختيار في المتصفح.
- اللغة الافتراضية لأول زيارة: `defaultLanguage` في `js/config.js`.
- الترجمات في `js/i18n.js`؛ لإضافة أو تعديل ترجمة أضف سطراً إلى `DICT` بالصيغة `'النص العربي': 'English'`.
- البيانات التي يُدخلها المستخدم (الأسماء، المشاريع، الملاحظات، أرقام اللوحات) تبقى كما أُدخلت ولا تُترجم.
- يمكن تحديد الاسم الإنجليزي للنظام من إعدادات المطور، والاسم الإنجليزي لصاحب الحقوق من `copyrightHolderEn` في `config.js`.

## تسجيل الدخول

- الدخول باسم المستخدم وكلمة المرور.
- **كلمة المرور الأولية** لكل الحسابات التجريبية محددة في `js/config.js` (`initialPassword`)، ويُلزَم كل مستخدم بتغييرها عند أول دخول.
- كلمات المرور تُحفظ كبصمة مشفرة (SHA-256 مع ملح عشوائي لكل مستخدم)، ولا تُحفظ كلمة المرور نفسها.
- يُقفل الحساب مؤقتاً لمدة 60 ثانية بعد 5 محاولات خاطئة (قابل للتعديل في `config.js`).
- مدير النظام يضيف المستخدمين بكلمة مرور مؤقتة ويعيد تعيينها عند النسيان، ويمكن لكل مستخدم تغيير كلمة مروره من زر المفتاح في الشريط العلوي.

| الدور | اسم المستخدم التجريبي |
|---|---|
| المطور | `dev` |
| مدير النظام | `salem` |
| المشرفون | `ahmed` ، `yousuf` |
| السائقون | `rashid` ، `imran` ، `saeed` ، `babu` |
| فريق الصيانة | `nasser` ، `rajesh` |

> **تنبيه أمني:** في هذه المرحلة يعمل النظام بالكامل داخل المتصفح بلا خادم، لذلك تحمي كلمة المرور الوصول من خلال الواجهة فقط، ولا تحمي البيانات المخزنة في المتصفح نفسه. للحماية الكاملة يجب ربط النظام بخادم مصادقة حقيقي (مثل Supabase Auth).

## الأدوار والصلاحيات

| الدور | ما يراه ويفعله |
|---|---|
| **المطور** | كل الصلاحيات + الهوية البصرية، الإعدادات، النسخ الاحتياطي والاستيراد |
| **مدير النظام** | إضافة/تعديل المعدات، ربطها بالمشاريع والإيجار، المشاريع والمشرفين، المستخدمين، المهام، اعتماد الفواتير وتقارير التشغيل |
| **المشرف** | متابعة مشاريعه، اعتماد ساعات التشغيل اليومية لمشاريعه، المهام |
| **السائق / المشغل** | معدته المسندة، تسجيل الساعات، إرسال ملاحظات وصور والإبلاغ عن الأعطال |
| **فريق الصيانة** | أوامر العمل، جدول الصيانة الدورية، تغيير حالة المعدات |

## أبرز الوظائف

- **بطاقة تعريف لكل معدة**: اللوحة ونوعها، التصنيف، اللون، السنة، الشاصي، الرخصة والتأمين (من/إلى) ونوع التأمين، العداد، الملاحظات.
- **حالات تشغيل ملونة**: 🟢 في العمل • 🔵 شاغرة/جاهزة • 🟡 في الصيانة • 🔴 خارج الخدمة.
- **التشغيل والإيجار**: ربط المعدة بمشروع داخلي أو عقد إيجار (ساعي / يومي / شهري) مع العميل والسائق والسعر.
- **تنبيهات تلقائية**: قبل انتهاء الرخصة أو التأمين بـ 30 يوماً، والصيانة الدورية حسب الساعات أو الكيلومترات.
- **ملاحظات الميدان**: بلاغ العطل من السائق يُنشئ تلقائياً مهمة صيانة للورشة ويحوّل المعدة إلى «معطلة».
- **المهام**: لوحة Kanban (جديدة ← قيد التنفيذ ← بانتظار الاعتماد ← مكتملة). إغلاق أمر صيانة يعيد المعدة للخدمة ويحدّث موعد الصيانة القادمة.
- **ساعات التشغيل**: يسجلها السائق، ويعتمدها المشرف، فيتحدث عداد المعدة تلقائياً.
- **الفواتير**: تقرير تشغيل شهري، وفواتير إيجار تُحسب من الساعات المعتمدة مع الضريبة، قابلة للطباعة.

## البيانات

- تُحفظ في `localStorage` بالمفتاح `almasiya_fleet_v1` — أي أنها خاصة بكل متصفح وجهاز.
- صدّر نسخة احتياطية (JSON) بانتظام من إعدادات المطور.
- عند الانتقال لاحقاً إلى خادم حقيقي (API / Supabase / Firebase) يكفي استبدال الدالتين `load` و `save` في `js/data.js`، مع إضافة تسجيل دخول حقيقي بكلمات مرور.
